LiDAR Project: Components and Estimated Cost

1. Project Type

Educational LiDAR and obstacle-detection prototype.

These are approximate planning estimates, not verified live prices. Actual costs depend on the seller and delivery charges.

3. How It Will Work

1. The distance sensor measures the distance to an object.
2. The ESP32 reads the sensor data.
3. The program compares the measured distance with a threshold.
4. An LED lights up when an object is within the chosen distance.

4. Important Note

The VL53L0X is a time-of-flight distance sensor. This project demonstrates basic optical distance measurement and obstacle detection; it does not provide the full capabilities of a professional LiDAR scanner.

5. Current Status

Components have not yet been purchased. The project is currently in the planning and learning phase.
